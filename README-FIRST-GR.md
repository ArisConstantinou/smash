## Σημαντική κατάσταση

Πρόκειται για έκδοση ανάπτυξης, όχι για εγγύηση ότι διορθώθηκε πλήρως
η πτώση στο 1 FPS. Δεν πραγματοποιήθηκε νέα δοκιμή gameplay ή μέτρηση
FPS σε πραγματική συσκευή κατά τη δημιουργία αυτού του ZIP.
Ελέγχθηκε η ακεραιότητα του αρχείου που ανακτήθηκε και του τελικού ZIP.

Στον κώδικα υπάρχουν η υποδομή WebGPU, ο μετρητής επιδόσεων και
το WebAssembly module συγκρούσεων μαζί με το έτοιμο collision.wasm.
Αυτό δεν σημαίνει ότι ολόκληρο το παιχνίδι μετατράπηκε σε WebAssembly
ή ότι έχει επιβεβαιωθεί βελτίωση FPS σε κάθε συσκευή.

Το renderer-policy.js επιλέγει WebGPU εξ ορισμού και δεν κάνει σιωπηλή
μετάβαση σε WebGL. Το ?renderer=webgl υπάρχει ως ρητή διαγνωστική επιλογή.
Το collision-wasm.js διατηρεί δυνατότητα χρήσης της JavaScript διαδρομής
όταν ο πυρήνας WASM δεν είναι διαθέσιμος.

Το παλαιότερο README.md αναφέρει ακόμη WebGL 2 ως απαίτηση. Για την παρούσα
έκδοση η επιλογή renderer περιγράφεται παραπάνω και στο renderer-policy.js.
Δεν διορθώθηκε το παλιό README ώστε να διατηρηθεί ακριβώς το source snapshot.

## Τοπική εκτέλεση

Αποσυμπίεσε ολόκληρο το ZIP. Άνοιξε τερματικό στον φάκελο που περιέχει
το index.html. Με εγκατεστημένη Python 3 εκτέλεσε:

    python -m http.server 8000 --bind 127.0.0.1

Στα Windows, εφόσον υπάρχει ο Python launcher, εναλλακτικά:

    py -3 -m http.server 8000 --bind 127.0.0.1

Άνοιξε στον browser:

    http://localhost:8000/

Για ρητή σύγκριση με τον διαγνωστικό WebGL renderer:

    http://localhost:8000/?renderer=webgl

Μην ανοίγεις απλώς το index.html με διπλό κλικ ως file://.
Το παιχνίδι περιλαμβάνει τα τοπικά assets και τις βιβλιοθήκες vendor.
Δεν περιλαμβάνονται node_modules ούτε ιστορικό Git.

## Δοκιμές και συνέχεια στο Codex

Το package.json περιλαμβάνει:

    npm test
    npm run build:wasm

Οι δοκιμές του workflow χρησιμοποιούν Node.js 22. Η αναδημιουργία του WASM
ακολουθεί το tools/build-wasm.sh και απαιτεί τα εργαλεία που ορίζει αυτό
το script. Το έτοιμο assets/wasm/collision.wasm περιλαμβάνεται ήδη.
Οι δοκιμές browser βρίσκονται στο tests/ και έχουν πρόσθετες απαιτήσεις.

Για συνέχεια της εργασίας, άνοιξε ολόκληρο τον φάκελο στο Codex.
Μην θεωρήσεις τα ακόλουθα ολοκληρωμένα χωρίς αναπαραγωγή και μέτρηση:

1. Έντονη πτώση FPS όταν το whirlwind χτυπά κτίρια και εχθρούς.
2. Έλεγχος πριν, κοντά και μετά το 38% συνολικής καταστροφής. Το 38% είναι
   σημείο που υπέδειξε ο χρήστης, όχι επιβεβαιωμένο αίτιο ή όριο.
3. Οπτική επιβεβαίωση ότι το WebGPU σχεδιάζει σωστά ολόκληρη τη σκηνή,
   όχι μόνο ότι αρχικοποιείται ή αναφέρει draw calls.
4. Διόρθωση της στάσης των χεριών όταν κρατούν ή χτυπούν με τεράστιο σφυρί.
5. Κλωτσιές που σπρώχνουν αυτοκίνητα κατά μέτρα και ορατές προσκρούσεις
   σε τοίχους και εχθρούς, με φωτιά και καπνό σε προχωρημένη ζημιά.
6. Μετρητής FPS πάνω δεξιά χωρίς να καλύπτει χειριστήρια και με ειλικρινείς
   μετρήσεις πραγματικού χρόνου καρέ.
7. Συγκρίσιμες δοκιμές JS/WASM και WebGL/WebGPU: η αλλαγή τεχνολογίας
   από μόνη της δεν τεκμηριώνει ότι λύθηκε η αρχική πτώση FPS.
